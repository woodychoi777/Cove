# Security and private data

Cove keeps music and records in a local library and serves the app on loopback only. Keep the library, AppData/profile and exports private. Never include music, databases, personal notes, credentials or unredacted service logs in public issues.

For a security problem, use the repository's private vulnerability reporting when enabled. Describe reproduction with synthetic data and the Cove/OS versions. Do not publish exploit details or personal files in a public issue while disclosure is being coordinated. This project does not currently provide an independently audited security guarantee.
